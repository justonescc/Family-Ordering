# 小程序点菜页体验优化 · PRD

> 父任务：11-23-miniprogram（小程序化改造）
> 定位：把「点菜」Tab 从「能用」提升到「对齐主流点餐小程序的观感与效率」。

## Goal

参考市面主流点餐小程序（美团/饿了么/喜茶/海底捞/点都德等）的通用交互范式，优化小程序「点菜」Tab 的信息架构与视觉：左分类 + 右菜品双栏联动、分组标题吸顶、菜品卡片、底部购物车栏与已选弹层，让家人点菜更快、更不容易漏。

## Background（已确认事实）

- 工作区已把 `miniprogram/src/pages/menu/index.tsx` 改成双栏结构（未提交）：左 `cat-nav` + 右 `dish-scroll` + 底部 `cart-bar` + 已选弹层 `cart-pop`，并带滚动联动高亮（`groupOffsets` 估算行高 + `onListScroll`）。
- **但 `miniprogram/src/pages/menu/index.scss` 目前只有 `.dish-thumb` / `.dish-thumb-empty`**；tsx 里新增的 `menu-page`、`cat-nav`、`cat-nav-item(-active)`、`cat-nav-badge`、`dish-card*`、`cart-bar`、`cart-pop*`、`scroll-pad` 等类名**全部没有样式定义**，当前渲染处于「无布局」状态。本次必须补齐样式。
- 现有滚动联动估算常量：`GROUP_TITLE_PX=44`、`DISH_ROW_PX=76`、`GROUP_GAP_PX=10`，经 `px()` 换算后与 `scrollTop` 比较（`miniprogram/src/pages/menu/index.tsx:20-23,76-84`）。
- 后端契约字段有限：`Dish = { id, categoryId, name, description?, imageUrl?, enabled }`，**没有价格、销量、标签、规格**；`OrderItem = { id, dishId?, dishName, qty, struck }`。因此「价格 / 月售 / 规格选择」类主流元素在本项目不可做。
- 自定义菜走 `upsertMyOrder({ dishName, qty: 1 })`，当前入口**只**在购物车弹层底部。
- 技术栈：Taro 4.3.3 + React 18 + 小程序原生 tabbar。`ScrollView` 支持 `enableFlex` + `usingSticky`（weapp），分组标题吸顶可行。
- 菜单页是 tab 页，底部购物车栏需避开原生 tabbar 高度；`app.scss` 已有 `search-bar` / `qty-btn` / `btn-solid` / `card` / `empty` 等通用件可复用。
- 现有通用规范：禁止组件内直接请求（走 `services/api.ts`）；渲染期禁止 impure 调用；点击目标 ≥ 44px；底部固定栏需处理安全区。

## 关键决策（已定）

1. **范围 = 精修版（F1–F6）**：做布局 / 视觉 / 交互精修，**不做**菜品大图详情弹层（用户 2026-11-24 确认）。
2. **自定义菜入口 = 左栏底部固定项**「＋ 自定义菜」，点击弹出输入弹层直接加；弹层内输入区保留作为补充入口（用户 2026-11-24 确认）。
3. **底部栏去掉主按钮**：底部栏 = 购物车图标（含总数角标）+「已选 N 份 / 还没有选菜」，整条栏可点展开已选弹层；不再放「我的单」按钮，避免与 tabbar 的「我的单」重复（用户 2026-11-24 确认）。

## Requirements

### F1 布局与视觉补齐（必做）
- 页面根容器 flex 纵向占满可视区：顶部区（标题 / 日期 / 餐次 / 搜索）固定，中部双栏 `flex:1` 且左右各自独立滚动，底部购物车栏吸底并避开原生 tabbar 高度。
- 左栏：固定宽约 160–180rpx 纵向滚动；选中项品牌色高亮 + 左侧竖条；分类名右侧数量角标。
- 右栏：分组标题 + 菜品卡片列表，底部预留 `scroll-pad` 防止被购物车栏遮挡。
- 底部栏：购物车图标（含总数角标）+「已选 N 份」，点击展开已选弹层。

### F2 分组标题吸顶
- 右栏滚动时当前分组标题吸附在右栏顶部（`usingSticky` + `position: sticky`），提升长列表定位效率；不支持时退化为普通标题，不阻塞。

### F3 菜品卡片
- 缩略图约 120–140rpx 圆角（无图占位），名称加粗、描述**单行截断**（保证卡片行高恒定，滚动联动估算才准确），右侧数量步进器复用 `qty-btn`。
- 保持「无价格」现实，不虚构价格字段。

### F4 已选弹层（购物车）
- 复用现有 `cart-pop`，补充：头部「清空」操作；按现有顺序列出已选，支持 `− / +` 与删除；自定义菜区域保留。
- 弹层内数量变化即时同步右栏步进器与左栏角标（`save()` 返回全量 `orders`，天然同步）。

### F5 自定义菜入口（左栏底部固定项）
- 左栏容器 flex 纵向：分类 `ScrollView` 占满剩余高度，底部固定一项「＋ 自定义菜」，不随分类滚动。
- 点击弹出输入弹层（`Input` + 「加入」），复用 `addCustom()` 逻辑；加入后展开已选弹层（现状行为）。
- 自定义菜无 `dishId`，不计入左栏分类角标，但计入底部栏总份数（需在实现中保持该口径）。

### F6 空态 / 加载态 / 搜索态
- 复用 `empty` / `muted`；搜索时隐藏整个左栏（含自定义项，现状已做），结果为空有专门空态（现状已做）。

## Acceptance Criteria

- [ ] 菜单页双栏正确布局：左栏与右栏各自独立滚动，底部购物车栏始终吸底且不遮挡内容（含全面屏 safe area）。
- [ ] 左栏选中分类高亮并带数量角标；点击分类右栏滚动到对应分组，滚动右栏左栏高亮跟随（偏移估算与实际行高一致，无可见漂移）。
- [ ] 右栏滚动时分组标题吸顶。
- [ ] 菜品卡片缩略图 / 名称 / 描述 / 步进器排版整齐，长名称与长描述不撑破布局（描述单行截断）。
- [ ] 底部栏实时显示已选总份数（含自定义菜）；点击整条栏展开已选弹层，可清空、可增减、可加入自定义菜。
- [ ] 左栏底部「＋ 自定义菜」入口可见且能弹出输入弹层、成功加入。
- [ ] 搜索态隐藏左栏，结果分组正常展示与加购。
- [ ] 空菜单 / 加载失败 / 搜索无结果三种状态展示正常。
- [ ] `npm run typecheck`、`npm run build:weapp` 通过；开发者工具 / 真机目视无错位。
